4. UNIVERSAL MULTI-DOMAIN CODE & SOLUTION ENGINE
================================================================================

One of NOVA AI's major technological achievements is its Universal Code Engine
(api/_lib/universalCodeEngine.js). It eliminates code truncation, half-baked code,
and the limitation of defaulting to simple calculator snippets.

NOVA AI outputs up to 4,096 tokens per generation of 100% complete, runnable code:

Domain-Specific Generators:
  1. Interactive Gaming Engine:
     Generates complete HTML5 Canvas arcade games (such as 60 FPS Cyber Snake,
     Pong, Breakout) with full state loops, local high-score persistence, keyboard
     listeners, neon particle effects, and responsive canvas scaling.

  2. Productivity Applications:
     Generates production-ready SPA utilities (Task Master Kanban/To-Do apps, Note
     vaults, Expense trackers) featuring localStorage persistence, category
     filtering, item counters, and keyboard accessibility.

  3. Developer Portfolios & Landing Pages:
     Synthesizes modern responsive portfolio websites with sticky glassmorphic
     navigation bars, hero headers with badge highlights, animated skill grids,
     interactive project showcases, and functional contact forms.

  4. System & Automation Scripts:
     Writes production-grade Python scripts (DataProcessor, web scrapers, automation
     tools) with strict type hints (typing), robust try...except exception
     boundaries, and argparse CLI interfaces.

  5. Math & Financial Tools:
     Generates 3D neo-glass calculators with aligned 4-column CSS Grid layouts
     (grid-template-columns: repeat(4, 1fr)), keyboard bindings, history logs, and
     scientific functions.

  6. Dynamic Synthesizer:
     For any arbitrary prompt, writes standalone, copy-paste ready HTML, CSS,
     JavaScript, Python, or SQL with fully closed fences and zero placeholders.

Proprietary "Code Stashing" & Syntax Highlighting Architecture:
  - The Problem: Standard markdown parsers split paragraphs on double line-breaks
    (\n\n). When code blocks contain empty lines, traditional parsers break the
    <pre><code> block into separate <p> elements, causing code text to inherit dark
    body text colors and become unreadable on dark backgrounds.
  - NOVA AI's Solution:
      a) Stashing Phase: Before markdown parsing, every ```...``` code block is
         isolated and replaced with a protected alphanumeric token (@@@NOVACODEBLOCK0@@@).
      b) Formatting Phase: Markdown bold, italic, lists, and tables are processed
         cleanly without corrupting code indentation or backticks.
      c) Syntax Highlighting Engine: Each stashed code block is tokenized into keywords
         (#79c0ff), strings (#7ee787), numbers/booleans (#ffa657), functions (#d2a8ff),
         tags (#7ee787), and comments (#8b949e) using an HTML tag-stashing replacer
         (___NVTAG${i}___) to prevent regex attribute collisions.
      d) Restoration Phase: Pristine, syntax-highlighted code blocks with copy-buttons
         and language badges are injected back into the DOM.
      e) Zero Black Text Guarantee: Enforces #e6edf3 base text color on all pre/code
         blocks with dark #0d1117 GitHub-inspired backgrounds.

9. PRODUCTION DEPLOYMENT & RUNNING NOVA AI
================================================================================

Mode A: One-Click Vercel Deployment (Recommended)
  1. Push the repository to GitHub.
  2. Import the project into Vercel (https://vercel.com).
  3. Add the optional environment variables in Vercel Project Settings:
       - GEMINI_API_KEY (from Google AI Studio)
       - OPENROUTER_API_KEY (optional, for Gemma & Nemotron models)
       - MONGODB_URI (optional, for persistent cloud database)
       - JWT_SECRET (optional, for secure user sessions)
  4. Click Deploy. Vercel automatically maps /api/* to serverless functions.

Mode B: Local Node.js Server (Offline & Private)
  1. Install dependencies:
       npm install
  2. Configure environment (Optional - works even with empty keys):
       cp .env.example .env
  3. Start the local server:
       npm start
     Output: NOVA AI is running at http://localhost:3000

Mode C: Zero-Config Static Preview
  Simply open dashboard.html directly in any modern web browser. The built-in
  client-side fallback engines will immediately handle code generation, task
  management, and voice interactions directly within the browser runtime.
